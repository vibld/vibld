# Generated data

`design-templates.ts`, `design-template-index.ts` and `screen-patterns.ts`
are generated by
[`../bin/import-design-catalog.ts`](../bin/import-design-catalog.ts) and are
never edited by hand. To change them, change the importer or a catalog and
run it again, on a checkout of `Drummond-IT/designs-v1`:

```bash
node --experimental-strip-types packages/ai/bin/import-design-catalog.ts \
  <path to the designs-v1 checkout> [google fonts metadata json]
```

`design-template-type.ts` and `saas-template-type.ts` are the typefaces
chosen for vibld (docs/decisions.md, D103 and D108); the importer reads them.

## Where the catalog comes from

Two batches, each recorded in `design-templates.ts` (`sources`) with the last
commit that changed it.

### The design prompt catalog

- Source: `design-prompt-catalog/` in the private repository
  `Drummond-IT/designs-v1`.
- It was added there by commit `40f523b` (2026-09-30). Its README describes
  the 207 entries as "original app and website designs" whose names, sample
  data and copy are invented.
- That repository has no licence file, and `design-prompt-catalog/` carries
  none of its own.

### The SaaS screen patterns

- Source: `saas-screen-patterns/` in the same repository, added by commit
  `5fc5f87` (2026-09-30) on its branch `claude/saas-screen-patterns-aj8tc9`
  (its internal pull request 5, not merged there when this was imported).
- Its README describes the 237 entries (149 app screens, 60 marketing sites,
  28 starters) as "original SaaS design patterns for clean-room reference",
  says every name, sample data point and piece of copy is invented and that
  nothing was copied, and says "This folder makes no licensing decisions."
- It carries no licence file of its own. Its `scripts/validate.py` reports
  "237 entries, 1872 contrast pairs checked, 0 problems" at that commit; the
  importer measures the same 1,872 pairs again with vibld's own code.

## What the importer changes

- Nothing in any entry's words except its em-dashes (docs/decisions.md,
  D87): 73 of them across both batches, rewritten as `--` in prose and as
  an en-dash where a design quotes the glyph an empty cell shows; and each
  design's typefaces, renamed where its set replaces them (D103, D108).
- A SaaS entry's spacing given as named parts (37 of them) becomes one
  line, "Density: ... Grid: ...", in its own order and words.
- It adds vibld's own fields beside the catalog's: `kind`, `useCase`,
  `format`, `batch`, `mergedInto` (D85, D107), and each design's palette as vibld's fifteen colour tokens
  (`style.tokens`), with any token solved rather than drawn named in
  `style.derived`.

## The style gallery

`style-gallery.json` is generated by
[`../bin/import-style-gallery.ts`](../bin/import-style-gallery.ts)
(docs/decisions.md, D142) and never edited by hand. To change it, change the
importer or the catalog and run it again, on a checkout of
`Drummond-IT/designs-v1`:

```bash
pnpm --filter @vibld/ai import:style-gallery <path to the designs-v1 checkout>
```

Add `--check` to compare without writing. `packages/ai/test/style-gallery.test.ts`
does the same when a checkout sits beside this repository or `DESIGNS_V1`
names one.

- Source: `style-gallery-patterns/style-gallery-patterns.json` in
  `Drummond-IT/designs-v1`, last changed by commit `01d9f42` (2026-10-02,
  its internal pull request 6). The commit is recorded in the file's `source`.
- Its README describes 1,342 "original website style presets for
  clean-room reference", "derived from measurements of public marketing
  sites", with every name, description and prompt newly written, and says
  "This folder makes no licensing decisions." It carries no license file of
  its own, and the repository has none.
- The public export leaves this file out until Chris decides otherwise
  (D143).
