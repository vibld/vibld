# Generated data

`design-templates.ts` and `design-template-index.ts` are generated by
[`../bin/import-design-catalog.ts`](../bin/import-design-catalog.ts) and are
never edited by hand. To change them, change the importer or the catalog and
run it again:

```bash
node --experimental-strip-types packages/ai/bin/import-design-catalog.ts \
  <path to design-prompt-catalog> <commit sha of that checkout>
```

## Where the catalog comes from

- Source: `design-prompt-catalog/` in the private repository
  `Drummond-IT/designs-v1`, at the commit recorded in
  `design-templates.ts` (`source.commit`).
- It was added there by commit `40f523b` (2026-09-30). Its README describes
  the 207 entries as "original app and website designs" whose names, sample
  data and copy are invented.
- That repository has no licence file, and `design-prompt-catalog/` carries
  none of its own.

## What the importer changes

- Nothing in any entry's words except its em-dashes (docs/decisions.md,
  D87): 63 of them, rewritten as `--` in prose and as an en-dash where a
  design quotes the glyph an empty cell shows.
- It adds vibld's own fields beside the catalog's: `kind`, `useCase`,
  `mergedInto`, and each design's palette as vibld's fifteen colour tokens
  (`style.tokens`), with any token solved rather than drawn named in
  `style.derived`.
