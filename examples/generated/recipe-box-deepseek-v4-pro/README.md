# Recipe Box

A browser-only recipe box. Save recipes with ingredients and numbered steps, search by name or ingredient, scale servings with quantities following, and mark favourites. All data is stored in your browser's localStorage and never leaves your device.

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

Open the local URL printed in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
```

Produces a production build in the `dist` folder.

## Typecheck

```bash
npm run typecheck
```

## Lint

```bash
npm run lint
```

Runs TypeScript checks. No account or network service is required.
