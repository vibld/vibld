# Working with Chris on Vibld

## Do the work; do not hand over commands

Never reply with a terminal command for Chris to run. Run it. If a step
genuinely cannot be run from this environment -- a credential that is not
here, a value only he has -- say that in one line, and put everything around
it into something that does run: a workflow step, a script, a committed
config change.

A command in a reply is an admission that the task was not finished.

## Instructions: concise, exact, with URLs

When Chris does have to do something himself, give the shortest exact path:

- a real URL, not "go to Settings -> ..."
- the literal field names and values
- no explanation of why, unless he asked

If a deep link cannot be constructed, say so in one line and give the nearest
URL that can be.

## Everything else

Ask rather than infer. This file is short because only what he has actually
said belongs in it.
