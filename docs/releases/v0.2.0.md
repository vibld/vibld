vibld 0.2.0: the open-source AI app builder that turns a description into a conventional React and TypeScript project you can read, run and take with you. It is the first release with a way to build a real project from a clone with only your own key.

This is the code running at [app.vibld.com](https://app.vibld.com), a public beta. See [Status](https://github.com/vibld/vibld#status) for what works and what does not yet.

## Build a real project with your own key

One provider key is all it needs: no account, database or Cloudflare.

```bash
git clone https://github.com/vibld/vibld.git && cd vibld
pnpm install --frozen-lockfile
export DEEPSEEK_API_KEY=...   # or ANTHROPIC_API_KEY, or OPENAI_API_KEY
pnpm generate "A one-page site for a neighbourhood bakery" --out ./my-site --build
cd my-site && npm run dev
```

- **The same build as the hosted service:**
  - a plan and a written design spec;
  - files in bounded steps;
  - design checks;
  - a verification build, with one repair if it fails.
- **Proof on every release:** a weekly workflow proves this path from a fresh clone of this repository. On the release day, a one-page site on DeepSeek's default model cost $0.15 to $0.31 and took 7 to 17 minutes.
- **Your key stays out of the project:** with `--build`, the generated project's install and build run with no credentials in their environment.

## Known limits

- **Self-hosting on Cloudflare is documented but not yet validated** by anyone outside the project.
- **The builder's interface runs a fake provider on your own machine.** Its real model path needs a Cloudflare deployment. `pnpm generate` is the local way to a real build.
- **Repository search over an existing codebase is not built.**
