vibld 0.4.0: the open-source AI app builder that turns a description into a conventional React and TypeScript project you can read, run and take with you. This release runs the whole builder on your own machine with Docker and no cloud account, builds with a local model, and adds a gallery of styles to build in.

This is the code running at [app.vibld.com](https://app.vibld.com), a public beta. See [Status](https://github.com/vibld/vibld#status) for what works and what does not yet.

## Run it yourself, without a cloud account

- **Docker.** `docker compose up --build` runs the builder, previews and publishing on one machine, with your projects in a Docker volume. Each preview's sandbox is its own container on your Docker. See [Run it with Docker](https://github.com/vibld/vibld#run-it-with-docker).
- **Sign in with no paid service.** A copy signs in with one owner password (`VIBLD_AUTH=owner`) or with Cloudflare Access in front of it (`VIBLD_AUTH=access`). Clerk stays available, and there is still no mode without sign-in.
- **Local models.** Ollama, LM Studio or llama.cpp, through their OpenAI-compatible endpoint, set with `VIBLD_LOCAL_BASE_URL` and `VIBLD_LOCAL_MODEL`. A local model is priced at zero, and a build it cannot finish says so plainly. See [Local models](https://github.com/vibld/vibld#local-models).
- **Previews in the browser.** A copy without a sandbox (Cloudflare's free plan, or a host with no Docker socket) bundles the preview in the viewer's browser with esbuild-wasm.
- **Render and your own server.** A Deploy to Render button runs the builder alone on one port, and `infrastructure/vps/cloud-init.yaml` sets up an Ubuntu server with sandbox previews and publishing behind a TLS proxy.
- **The Self-host check now signs in and builds.** The workflow deploys a separately named copy, signs in with the owner's password, builds one site with a real model and opens its preview, on Cloudflare and under Docker.

## Admin panel

- **Accounts:** every account, with plan, status, projects and spend, search, filters and a CSV export, and a page per account with its monthly spend, running builds and live sites.
- **Platform overview:** sign-ups, builds and how they ended, model spend and money taken, over the last 7, 30 or 90 days.
- **Provider keys:** set, replace and remove a deployment's Anthropic, DeepSeek and OpenAI keys. They are stored encrypted and shown only by their last four characters.
- **Plans:** each plan's project limit and monthly allowance, and which models each plan includes, with extra models for one person.

## Styles and templates in the builder

- **1,300+ styles** in a new Gallery option: filter by theme, look and industry, and a build writes the chosen style's colors, type, corners and shadows into the project as Tailwind tokens, with its fonts self-hosted. Browse them at [vibld.com/styles/gallery](https://vibld.com/styles/gallery).
- **A contrast guard** on the style's colors: an edit that breaks any of the style's measured contrast pairs is not applied, and the panel says which.
- **Templates** in the composer: the 400+ designs and screens from [vibld.com/templates](https://vibld.com/templates), added to a message as inspiration.

## Fixes

- Fonts that can take any weight now load their real range, so bold text is no longer drawn by thickening the regular weight.
- vibld.com's sitemap lists every gallery page, and its tests run on their own in CI.

## Known limits

- **Self-hosting is checked by the project, not yet by anyone outside it.** Nobody has deployed to Render or run `cloud-init.yaml` on a real server yet.
- **Not under Docker:** the nightly cleanup jobs, Stripe, GitHub push and email.
- **Repository search over an existing codebase is not built.**
