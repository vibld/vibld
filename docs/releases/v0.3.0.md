vibld 0.3.0: the open-source AI app builder that turns a description into a conventional React and TypeScript project you can read, run and take with you. This release makes the template catalog something you can build from, and adds a checked way to deploy your own copy.

This is the code running at [app.vibld.com](https://app.vibld.com), a public beta. See [Status](https://github.com/vibld/vibld#status) for what works and what does not yet.

## Start from a template

- **400+ designs and screens** at [vibld.com/templates](https://vibld.com/templates):
  - 200+ app and website designs, each with its own typefaces, a mocked homepage preview, filters and sorting;
  - 100+ app screens (dashboards, settings, onboarding and more), each with its patterns, states and guardrails, to add to a design.
- **"Start from this template"** fills the builder with the design's full brief. Briefs of up to 40,000 characters are accepted, and a long brief goes straight to a build as written.
- **Built from one prompt:** two pages at [vibld.com/templates](https://vibld.com/templates) show the prompt each was built from, with a copy button.
- **The four animated backgrounds** now run live at [vibld.com/styles](https://vibld.com/styles), from the same source a build writes into a project.

## Deploy your own copy, checked

- **`scripts/self-host.mjs`** writes each Worker's Wrangler configuration for your copy from one settings file. Every Worker, database, bucket, Workflow and rate-limit namespace is named from your prefix, and it refuses to write a configuration that still names vibld's own deployment. Without a preview domain of your own, publishing stays off rather than publishing under vibld's domain.
- **A Self-host check workflow** deploys a separately named copy from the docs in the documented order, confirms it comes up and refuses a signed-out caller, then removes everything it created.
- [vibld.com/docs/deploying](https://vibld.com/docs/deploying) now uses the script, and says why the builder goes last.

## Fixes

- **DeepSeek outlines:**
  - the retry of a plan that ran out of room now gets twice the room whenever the model's thinking took a quarter of the first reply;
  - a plan wrapped in a code fence is read;
  - a reply that is not a plan now says how long it was, how it ended and how it began.
- **Counts on vibld.com** are rounded down ("200+"), and the site deploys on every change to main.

## Known limits

- **Self-hosting on Cloudflare is checked by the project, not yet by anyone outside it.** The check stops at a signed-out copy: sign-in and generation on a copy are not checked.
- **The builder's interface runs a fake provider on your own machine.** Its real model path needs a Cloudflare deployment. `pnpm generate` is the local way to a real build.
- **Repository search over an existing codebase is not built.**
