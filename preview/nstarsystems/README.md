# nstarsystems.com preview (throwaway)

A Vibld-generated project (checkpoint `rfb9716f0`), copied out of a browser
session's local state and deployed as a real Cloudflare Worker purely so it
can be viewed live -- the builder shell's own preview pane only renders a
local static mock, and the generated project needs an actual `npm install &&
vite build` before it can run.

This directory, and the `preview/nstarsystems` branch it lives on, is not
part of the Vibld product. It exists only to view this one generation and is
expected to be deleted once that's done -- see `.github/workflows/deploy-
preview-nstarsystems.yml` on this branch for how it's deployed.
